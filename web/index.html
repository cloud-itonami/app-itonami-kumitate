kumitate CircleCI-compatible pipeline planning

Validate a .circleci/config.yml (version 2.1), see the processed plan and the workflow graph, and summarize run records or JUnit reports. Everything runs in this browser: the page has no network access, and nothing you paste or open is sent anywhere.

Config

Pipeline values

Values you leave empty stay undecided: filters and conditions that depend on them are kept as written, with a warning.

Runs and tests

Open run records (CircleCI API v2 items JSON, or kumitate.runs.v1) or JUnit XML reports. Several JUnit files are summarized together.

kumitate is a Kotoba program compiled to WebAssembly by the Amu selfhost compiler. It only computes: it fetches no orbs, runs no job, and connects to neither CircleCI nor a VCS. Capabilities beyond the run's own input and output are refused until the shared consent broker lands (JUN-353 Phase 2).
